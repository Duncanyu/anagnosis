# Anagnosis

Anagnosis helps students and researchers turn messy PDFs and notes into searchable, citation-ready knowledge. It’s designed to save time: find definitions, formulas, and explanations without re-reading whole papers.

What you'll get

- A lightweight way to search academic files by concept, not just keyword.
- Answers that point back to original pages for easy citation.
- A toolset that understands math, tables, and structured content better than plain text search.

Who it's for

- University students studying dense material.
- Researchers collecting and organizing literature.
- Educators who need quick access to examples and formulas.

Status

Experimental. The core pipelines (parsing, retrieval, and UI) are present and evolving. This repo is both a working tool and a research/demo platform.
